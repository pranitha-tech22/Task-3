GREEN EARTH FOUNDATION — AI WEBSITE GENERATION PROJECT
=====================================================

What is included
- index.html: complete responsive website with Home, About, Services, Projects, Impact, Get Involved, Contact and footer sections.
- LINKEDIN_POST.txt: suggested post caption.
- SUBMISSION_CHECKLIST.txt: steps for publishing, screenshots and Google Drive.
- PROJECT_NOTES.txt: scope and limitations.

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.
3. Internet access is needed for the remote Unsplash photos.
4. The contact form is a front-end demo only. It does not send or store messages.

HOW TO PUBLISH
Option A — Netlify Drop:
1. Visit https://app.netlify.com/drop
2. Sign in if prompted.
3. Drag the extracted project folder (or a ZIP containing index.html at its root) into the upload area.
4. Wait for a published URL and open it to test the page.
5. Save the real URL in your submission folder.
If Netlify's current workflow asks for a Git repository or a different setup, follow its on-screen instructions.

Option B — Framer or Wix:
Use the design as a reference and recreate/import the page in the builder if supported. Publish through the builder and copy the actual live URL.

IMPORTANT
This is an advanced student demonstration website for a fictional environmental organization. It is not affiliated with InAmigos Foundation. The impact numbers are explicitly illustrative sample figures. Replace them with verified information before any real-world use.
